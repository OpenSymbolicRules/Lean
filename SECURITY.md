# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x (pilot) | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities, including any way to obtain a
`"certified": true` record without a valid kernel-checked proof, through a
GitHub Security Advisory (GHSA) on this repository:
<https://github.com/OpenSymbolicRules/Lean/security/advisories/new>.

Do not open public issues for security vulnerabilities.
